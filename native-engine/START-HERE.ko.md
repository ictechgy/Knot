# Knot 자체 엔진 실험판

두 기기에서 **Knot Native Preview**를 실행합니다. Sunshine 계정·웹 PIN·별도 원격 프로그램은 필요하지 않습니다. 기존 Knot과 나란히 둘 수 있습니다.

이번 **native.13은 Mac과 Windows를 모두 업데이트**해 주세요. 연결 중 **Windows 재생 소리, 파일·폴더 보내기·받기와 탐색기 드래그앤드롭**을 지원합니다. 소리 공유는 Windows에서 직접 켜야 하며 마이크는 포함하지 않습니다. 연결 순서는 **주변 PC 찾기 → PC 직접 선택 → 8자리 번호 입력**이며, 검색 결과가 한 대여도 직접 선택한 뒤 번호를 입력합니다.

1. Windows에서 **화면 공유 시작**을 누릅니다. 소리도 들으려면 시작 전에 **Windows 재생 소리 포함 · 마이크 제외**를 켜세요. 앱을 새로 열거나 업데이트 후 실행하면 기본은 꺼짐입니다. 표시된 **8자리 연결번호**를 아는 Mac 한 대가 2분 안에 이번 화면·입력 공유를 시작할 수 있습니다. 기본 화질은 최대 **4K·30fps·40Mbps**이며, 시작 전에 4K·60fps 또는 1080p·60fps 호환 모드를 고를 수 있습니다.
2. Mac 첫 화면에서 Windows 준비 안내를 읽고 **주변 PC 찾기**를 누릅니다. 목록에서 Windows의 이름·주소를 보고 **직접 PC를 선택**하면 번호 입력 화면이 나옵니다. 선택한 Windows의 Knot에 표시된 **8자리 번호**를 입력하고 **이 PC에 연결**을 누릅니다. 잘못 선택했으면 **다른 PC 선택**으로 돌아가세요. 입력한 번호는 지워집니다. 긴 초대장과 인증서 정보는 앱끼리 암호화해 전달하고, 실제 화면 연결은 전체 인증서 지문을 검증하는 별도 TLS로 시작합니다. Windows에서 다시 승인할 필요는 없습니다. 언제든 사이드바 **연결 안내**에서 순서를 다시 볼 수 있습니다.
3. 연결되면 Windows 화면을 조작합니다. **Mac 입력기가 기본**이므로 기존 Mac의 Caps Lock 한영 전환을 그대로 사용해 보세요. Caps Lock을 Windows Caps Lock으로 보내지 않습니다. Mac 단축키 모드에서는 ⌘C/V로 Windows 텍스트 복사와 Mac 텍스트 붙여넣기를 명시적으로 요청합니다. ⌘Z/A 등도 Ctrl 조합으로 바뀝니다. 연결 제어의 작업 도구에서 물리 키 모드로 바꿀 수 있습니다. 백그라운드 클립보드 동기화는 하지 않습니다.
4. 전체화면에서는 상하단 제어줄이 영상 높이를 차지하지 않습니다. 상단 제어를 펼치면 실제 수신 해상도, 연결 종료와 전체화면 나가기가 보입니다. 입력이 일시 정지되면 원격 화면을 클릭해 다시 활성화합니다. macOS의 Control+방향키 공간 전환은 유지합니다.
5. Windows **공유 중지** 또는 Mac **연결 종료**로 이번 권한을 취소합니다. 번호 연결 전에 **내 PC로 등록**을 선택하면 다음부터 **내 PC → 연결**로 접속합니다. 자격 증명은 Mac Keychain과 Windows CurrentUser DPAPI로 보호하고 초대장은 매번 새로 발급합니다. 등록한 연결의 일시적 끊김은 최대 6회 복구하며, 직접 종료하면 재시도를 멈춥니다. Mac 등록 해제 또는 Windows 연결 안내의 **등록한 Mac 관리**에서 해제할 수 있습니다.

Windows 원본이 3840×2160이면 최대 4K로 전송할 수 있습니다. 원본이 낮은 해상도면 확대해 4K인 것처럼 표시하지 않습니다. Windows 표시 모드나 가상 모니터를 만들지 않으며, 실제 화면 비율이 다르면 비율을 유지하는 여백은 생길 수 있습니다. GPU가 4K/60을 지원하지 않으면 호환 모드로 새 공유를 시작해 주세요. 정상 실행은 하드웨어 H.264 인코더를 요구합니다.

같은 LAN의 검색은 UDP를 사용합니다. Tailscale 너머로 LAN 방송이 전달되지는 않으므로, 검색되지 않을 때만 **다른 연결 방법**에서 Windows 공유 화면의 LAN/Tailscale IPv4 주소로 찾습니다. 검색 결과를 직접 선택한 뒤 번호를 입력하는 순서는 같습니다. 일반 경로에는 직접 IP 입력이 필요하지 않습니다. OS의 앱/로컬 네트워크 허용 창은 나타날 수 있으며 앱이 방화벽·보안 설정을 자동 변경하지 않습니다.

긴 초대장 호환 모드는 고급 항목입니다. Windows에서 기존 공유를 중지하고 별도 새 호환 공유를 시작한 뒤 긴 코드를 복사합니다. Mac에서 주소·전체 인증서 지문을 대조해 연결하고 Windows에서 명시적으로 허용합니다. 번호 방식의 이전 권한을 호환 모드로 넘기지 않습니다.

## Windows 소리 듣기 (native.13)

Windows에서 공유 시작 전에 **Windows 재생 소리 포함 · 마이크 제외**를 켜면 기본 재생 장치의 소리를 Mac으로 보냅니다. 마이크를 선택하거나 수집하지 않습니다. 허용은 이번에 직접 시작한 공유에만 적용하며, 이전 실행·업데이트 전의 복구 권한만으로 소리 공유를 켜지 않습니다. 두 앱을 모두 업데이트한 뒤 새 공유에서 직접 선택해 주세요.

자동 재연결이 Windows의 새 공유를 시작하면 소리 허용은 해제됩니다. 소리도 다시 공유하려면 Windows에서 공유를 중지한 뒤 소리 옵션을 켜고 직접 공유를 시작하세요.

Mac 연결 제어의 스피커 버튼으로 **음소거 / 소리 켜기**를 선택합니다. 이 버튼은 Mac에서 듣는 소리만 바꾸고 Windows 원본 볼륨은 바꾸지 않습니다. 음소거 중에도 수신 처리를 계속하므로 다시 켤 때 오래된 소리를 쌓아 재생하지 않습니다. 소리를 사용할 수 없거나 이전 버전과 연결해도 화면 연결은 유지됩니다. 공유 중지·연결 종료 시 소리 권한과 재생도 끝납니다.

스테레오48kHz·16비트 PCM을 별도 인증서 고정 TLS TCP48636으로 전송하며, 전송 오버헤드 전 약1.536Mbps가 추가됩니다. 현재 화면 연결에서 허용한 같은 상대만 사용할 수 있고 파일 접근 권한을 주지는 않습니다. 앱별 소리 선택·개별 볼륨, 마이크 전달, DRM 콘텐츠 재생이나 정밀한 영상·음성 동기화는 보장하지 않습니다. 별도 연결이어도 Wi-Fi 혼잡이나 실제 기기의 지연까지 없어지는 것은 아닙니다. [오디오 범위와 프로토콜](AUDIO.md).

native.13은 H.264 출력 샘플 형식 판별, 짧은 구간에서 반복되는 Mac 수신 부하의 화질 피드백, Windows 둥근 버튼 바깥 배경 다시 그리기도 수정합니다. 화질 피드백은 영상 압축 프레임을 임의로 건너뛰지 않고 기존 순서와 대기 한도를 유지합니다. 합성 검사는 특정 GPU의4K 끊김 원인을 확정하거나 실기기 성능 향상을 증명하지 않습니다.

## 연결 중 파일 보내기·받기

Windows에서 공유할 때 **파일 공유 폴더**를 확인하세요. 기본은 다운로드의 **Knot Files**이고, 공유 전에 다른 폴더를 고르거나 파일 공유를 끌 수 있습니다. 파일 권한과 수신 파일의 보안 표시를 지원하는 폴더가 필요하며, 확인에 실패하면 파일 공유만 사용할 수 없다고 안내합니다. 이 폴더 바로 안의 파일·폴더를 Mac 목록에 표시합니다. 공유 허용에는 탐색기에서 직접 끌어온 항목도 포함하며, 그 항목의 상위 폴더 전체를 공개하지 않습니다.

- **Mac → Windows:** 연결 제어의 **파일**에서 보내기를 누르거나, Finder 파일·폴더를 원격 화면·파일 패널 위에 놓습니다. 표시된 Windows 공유 폴더로 복사됩니다. 영상 속 Explorer의 마우스 위치에 저장하는 방식은 아닙니다.
- **Windows → Mac:** 파일 패널에서 파일을 골라 저장 위치를 선택하거나, 해당 항목을 Finder로 끌어옵니다. **Windows 탐색기에서 파일·폴더를 잡아 원격 화면 밖의 Mac Finder로 직접 끌어와도 됩니다.** Mac 쪽 파일 아이콘이 나타날 때까지 버튼을 누른 채 유지하세요. 중간에 놓거나 취소하면 연결 전환을 중단합니다. 여러 항목은 최대32개입니다.
- 진행률을 보며 취소할 수 있습니다. 파일 전송만 취소하면 화면 연결은 유지됩니다. 연결을 종료하면 파일 권한도 끝나고 미완성 임시 파일을 정리합니다. 원본은 지우지 않으며 기존 파일을 덮어쓰지 않습니다.

일반 파일과 폴더를 지원하며 빈 하위 폴더도 유지합니다. 앱 패키지·링크·하드링크·특수 파일은 전송하지 않습니다. 목록 최대256개, 보내기 대기 최대32개, 항목 하나 및 연결당 누적8GiB, 전송 속도 상한2MiB/s입니다. 폴더 하나에 하위 항목4096개·깊이16단계, 연결당 누적8192개 항목까지입니다. 취소한 전송도 해당 연결의 용량·항목 한도에 포함됩니다. 받은 파일은 자동 실행하지 않습니다. 파일 전송은 별도 암호화 연결을 쓰지만 Wi-Fi 혼잡에 따른 화면 품질 영향까지 없어진다는 뜻은 아닙니다.

Windows11 x64/Home의 로그인된 기본 SDR 가로 화면 → Apple Silicon/macOS26 이상을 대상으로 합니다. 마이크 전달·백그라운드 클립보드 동기화·무모니터·HDR·다중 모니터·잠금/UAC는 아직 이 실험판 범위 밖입니다. 서명 검증·자동 재실행 업데이트 코드는 추가됐지만 공개 배포 피드와 키가 구성되기 전에는 자동 다운로드하지 않습니다. [업데이트 배포 설정](UPDATES.md)을 참고하세요. Windows 미서명, Mac ad-hoc 서명·미공증 프리뷰이며 기존 앱의 설정·인증서·페어링은 가져오거나 초기화하지 않습니다.

자동검사는 새 합성 영상·임시 TLS·PAKE 데이터와 inert UI를 사용합니다. 오디오 검사는 가짜 캡처·출력과 새 합성 PCM 데이터만 사용하며 실제 소리를 수집하거나 재생하지 않습니다. 실제 Windows/GPU의 4K 품질, 한글 조합·Caps Lock, 전체화면·DPI, 소리와 두 기기 지연은 별도 실기기 검증이 필요합니다. [영문 설명](README.md), [미디어 프로토콜](PROTOCOL.md), [폴더·드래그 연결](TREES.md), [짧은 번호 인증](ENROLLMENT.md).

## 작업 편의 기능 (native.11)

### native.12 인증서 오류 수정

native.11의 공유 인증서는 키 크기·유효기간 때문에 Mac에서 거절될 수 있습니다. Windows 앱을 native.12로 업데이트한 뒤 기본 화면의 **호환 인증서로 전환하고 공유**를 직접 눌러주세요. 2048비트 RSA·365일 인증서를 만들고 기존 등록을 초기화한 뒤 공유를 시작합니다. Mac에서 새 8자리 번호로 연결하고, 원하면 내 PC로 다시 등록하세요. 새로 설치한 PC에는 이 전환 단계가 없습니다.

보안 검증을 끄거나 기존 인증서를 자동으로 신뢰하는 방식은 쓰지 않습니다. 인증서 불일치·Mac 정책 거절·네트워크 오류는 이제 별도 안내로 표시합니다.

메뉴 막대의 Knot 또는 **Control+Option+Command+B**로 Windows 창을 앞으로 가져옵니다. 마지막 전체화면·단축키·화질·재연결 설정을 기억합니다. 연결 제어의 **작업 도구**에서 자동/글자 선명도/반응 우선 화질을 선택합니다. 인코더가 연결 중 조절을 지원하지 않으면 현재 설정을 유지하고 안내합니다. 파일 패널의 **미완료 항목 재시도**는 완료 확인된 항목을 건너뛰며, **Finder에서 보기**는 마지막 수신 항목을 선택합니다. 바이트 단위 이어받기는 아직 없습니다.
