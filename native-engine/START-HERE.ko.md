# Knot 자체 엔진 실험판

두 기기에서 **Knot Native Preview**를 실행합니다. Sunshine 계정·웹 PIN·별도 원격 프로그램은 필요하지 않습니다. 기존 Knot과 나란히 둘 수 있습니다.

이번 **native.9는 Mac과 Windows를 모두 업데이트**해 주세요. 연결 중 **파일 보내기·받기와 드래그앤드롭**을 지원합니다. 연결 순서는 **주변 PC 찾기 → PC 직접 선택 → 8자리 번호 입력**이며, 검색 결과가 한 대여도 직접 선택한 뒤 번호를 입력합니다.

1. Windows에서 **화면 공유 시작**을 누릅니다. 표시된 **8자리 연결번호**를 아는 Mac 한 대가 2분 안에 이번 화면·입력 공유를 시작할 수 있습니다. 기본 화질은 최대 **4K·30fps·40Mbps**이며, 시작 전에 4K·60fps 또는 1080p·60fps 호환 모드를 고를 수 있습니다.
2. Mac 첫 화면에서 Windows 준비 안내를 읽고 **주변 PC 찾기**를 누릅니다. 목록에서 Windows의 이름·주소를 보고 **직접 PC를 선택**하면 번호 입력 화면이 나옵니다. 선택한 Windows의 Knot에 표시된 **8자리 번호**를 입력하고 **이 PC에 연결**을 누릅니다. 잘못 선택했으면 **다른 PC 선택**으로 돌아가세요. 입력한 번호는 지워집니다. 긴 초대장과 인증서 정보는 앱끼리 암호화해 전달하고, 실제 화면 연결은 전체 인증서 지문을 검증하는 별도 TLS로 시작합니다. Windows에서 다시 승인할 필요는 없습니다. 언제든 사이드바 **연결 안내**에서 순서를 다시 볼 수 있습니다.
3. 연결되면 Windows 화면을 조작합니다. **Mac 입력기가 기본**이므로 기존 Mac의 Caps Lock 한영 전환을 그대로 사용해 보세요. Caps Lock을 Windows Caps Lock으로 보내지 않습니다. Windows 안의 복사·붙여넣기는 Ctrl+C/V이고, 일반 물리 입력에서 Command는 Windows 키에 대응합니다.
4. 전체화면에서는 상하단 제어줄이 영상 높이를 차지하지 않습니다. 상단 제어를 펼치면 실제 수신 해상도, 연결 종료와 전체화면 나가기가 보입니다. 입력이 일시 정지되면 원격 화면을 클릭해 다시 활성화합니다. macOS의 Control+방향키 공간 전환은 유지합니다.
5. Windows **공유 중지** 또는 Mac **연결 종료**로 이번 권한을 취소합니다. 다시 연결할 때는 새 번호가 필요합니다. 번호와 초대장은 저장하지 않고, 저장된 페어링·자동 재연결을 구현한 것으로 표시하지 않습니다.

Windows 원본이 3840×2160이면 최대 4K로 전송할 수 있습니다. 원본이 낮은 해상도면 확대해 4K인 것처럼 표시하지 않습니다. Windows 표시 모드나 가상 모니터를 만들지 않으며, 실제 화면 비율이 다르면 비율을 유지하는 여백은 생길 수 있습니다. GPU가 4K/60을 지원하지 않으면 호환 모드로 새 공유를 시작해 주세요. 정상 실행은 하드웨어 H.264 인코더를 요구합니다.

같은 LAN의 검색은 UDP를 사용합니다. Tailscale 너머로 LAN 방송이 전달되지는 않으므로, 검색되지 않을 때만 **다른 연결 방법**에서 Windows 공유 화면의 LAN/Tailscale IPv4 주소로 찾습니다. 검색 결과를 직접 선택한 뒤 번호를 입력하는 순서는 같습니다. 일반 경로에는 직접 IP 입력이 필요하지 않습니다. OS의 앱/로컬 네트워크 허용 창은 나타날 수 있으며 앱이 방화벽·보안 설정을 자동 변경하지 않습니다.

긴 초대장 호환 모드는 고급 항목입니다. Windows에서 기존 공유를 중지하고 별도 새 호환 공유를 시작한 뒤 긴 코드를 복사합니다. Mac에서 주소·전체 인증서 지문을 대조해 연결하고 Windows에서 명시적으로 허용합니다. 번호 방식의 이전 권한을 호환 모드로 넘기지 않습니다.

## 연결 중 파일 보내기·받기

Windows에서 공유할 때 **파일 공유 폴더**를 확인하세요. 기본은 다운로드의 **Knot Files**이고, 공유 전에 다른 폴더를 고르거나 파일 공유를 끌 수 있습니다. 이 폴더 바로 안의 일반 파일만 Mac에 표시합니다. Windows 파일을 가져오려면 이 폴더에 넣거나, 공유 전에 그 파일이 있는 폴더를 선택하세요.

- **Mac → Windows:** 연결 제어의 **파일**에서 보내기를 누르거나, Finder 파일을 원격 화면·파일 패널 위에 놓습니다. 표시된 Windows 공유 폴더로 복사됩니다. 영상 속 Explorer의 마우스 위치에 저장하는 방식은 아닙니다.
- **Windows → Mac:** 파일 패널에서 파일을 골라 저장 위치를 선택하거나, 해당 파일 행을 Finder로 끌어옵니다. 영상 속 Explorer 파일을 직접 바깥으로 끄는 방식은 지원하지 않습니다.
- 진행률을 보며 취소할 수 있습니다. 파일 전송만 취소하면 화면 연결은 유지됩니다. 연결을 종료하면 파일 권한도 끝나고 미완성 임시 파일을 정리합니다. 원본은 지우지 않으며 기존 파일을 덮어쓰지 않습니다.

일반 파일만 지원하며 폴더·앱 패키지·링크는 전송하지 않습니다. 목록 최대256개, 보내기 대기 최대32개, 파일 하나 및 연결당 누적8GiB, 전송 속도 상한2MiB/s입니다. 취소한 전송도 해당 연결의 용량 한도에 포함됩니다. 받은 파일은 자동 실행하지 않습니다. 파일 전송은 별도 암호화 연결을 쓰지만 Wi-Fi 혼잡에 따른 화면 품질 영향까지 없어진다는 뜻은 아닙니다.

Windows11 x64/Home의 로그인된 기본 SDR 가로 화면 → Apple Silicon/macOS26 이상을 대상으로 합니다. 오디오·클립보드 동기화·폴더 전송·무모니터·HDR·다중 모니터·잠금/UAC·자동 업데이트는 아직 이 실험판 범위 밖입니다. Windows 미서명, Mac ad-hoc 서명·미공증 프리뷰이며 기존 앱의 설정·인증서·페어링은 가져오거나 초기화하지 않습니다.

자동검사는 새 합성 영상·임시 TLS·PAKE 데이터와 inert UI를 사용합니다. 실제 Windows/GPU의 4K 품질, 한글 조합·Caps Lock, 전체화면·DPI와 두 기기 지연은 별도 실기기 검증이 필요합니다. [영문 설명](README.md), [미디어 프로토콜](PROTOCOL.md), [짧은 번호 인증](ENROLLMENT.md).
