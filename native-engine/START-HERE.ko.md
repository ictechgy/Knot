# Knot 자체 엔진 실험판

Sunshine·Moonlight를 설치하거나 실행하지 않는 별도 시험 앱입니다. 기존 Knot과 나란히 둘 수 있습니다.

1. Windows11 x64에서 설치 EXE로 **Knot Native Preview**를 설치해 엽니다. WindowsHome도 대상입니다. **화면 공유 시작 → 연결 코드 복사**로 새 코드를 만듭니다. 기본 LAN/Tailscale 경로가 표시되며, 바꿀 때만 네트워크 선택을 펼칩니다.
2. Mac에 DMG의 **Knot Native Preview.app**을 Applications로 옮겨 실행합니다. **원격 데스크톱**에서 코드를 붙여 넣고 **코드 확인**을 누릅니다. 대상 주소와 인증서 지문을 Windows 공유 화면의 값과 대조한 뒤 **이 PC에 연결**을 누릅니다. 코드 확인만으로 연결이 시작되지 않습니다.
3. Windows에서 실제 연결 주소와 신원이 확인되지 않은 요청 이름을 확인하고 **연결 허용**을 누르면 화면과 입력을 준비합니다. 이름은 참고 정보이며 인증된 신원이 아닙니다. **공유 중지** 또는 Mac의 **연결 종료**로 이번 권한을 없앱니다.

연결 전에는 코드 입력과 PC 확인만 표시되고, 연결 중에는 원격 화면이 창을 채웁니다. Mac 이름과 상세 설명은 접힌 항목에, 지원 범위와 연결 방법은 **연결 안내**에 있습니다. 입력이 일시 정지되면 화면을 클릭해 다시 활성화합니다. 한글은 화면 하단의 **한글 · Mac 입력기**를 켜서 시험해 주세요.

코드는120초·1회용이며 매 연결마다 새로 필요합니다. 선샤인 계정·웹 PIN·SSH 설정은 없습니다. 파일·오디오·무모니터·HDR·다중 모니터·로그인/잠금/UAC 화면·저장된 페어링·자동 업데이트는 아직 이 실험판 범위가 아닙니다. 실제GPU의 하드웨어H.264 인코더가 필요하고, 지원하지 않으면 소프트웨어로 몰래 전환하지 않고 안내합니다. 초기는 로그인한 기본 SDR 가로 화면으로 시험해 주세요.

Mac은 AppleSilicon/macOS26 이상이 필요합니다. Windows는 미서명, Mac은 ad-hoc서명·미공증 프리뷰라 실행 차단이 남을 수 있습니다. 기존 앱의 인증서·페어링·설정을 가져오거나 초기화하지 않습니다.

승인 후 인코더 초기화가 느리면 Ready 전에는 최대65초 동안 새 데이터를 기다리며, 승인·초기화 전체 대기는125초로 제한됩니다. 화면이 준비된 뒤의 무응답 제한은10초입니다. 인증서의 유효기간을 넓혀 시계 오차를 허용하지만, 초대 코드의120초·1회용 제한과 지문·유효기간 검증은 계속 적용됩니다.

자동검사는 실제 캡처·사용자 화면·키보드 주입 없이 새 합성 영상과 임시 TLS 인증서로 실행합니다. 실제 WindowsHome/GPU와 두 기기 화면·입력·색·지연은 별도 실기기 검증이 필요합니다. [영문 구현·빌드·제한](README.md), [프로토콜](PROTOCOL.md).
